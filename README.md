A travel poster for **AURELIA — The Floating Isles**, a place that does not
exist: lush green islands floating above a sea of clouds at golden hour,
waterfalls pouring off their edges into the clouds below, a glowing
crystalline lighthouse on the largest isle, and airships and hot-air
balloons drifting between them. The place name is set into the picture in
large gold vintage type.

## How it works

`main.ts` (Node 22, no network) copies `entry.png` to `/output/entry.png`.

```sh
node main.ts
```
